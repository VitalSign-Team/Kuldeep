ABOUT THE PROJECT

🏥 VitalSign Healthcare Analytics

VitalSign is a healthcare analytics and machine learning application designed to analyze hospital patient data and identify useful patterns.

The project uses the Diabetes 130-US Hospitals dataset and applies multiple machine learning techniques including regression, classification and clustering.
